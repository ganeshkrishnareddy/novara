# GitHub community feature report

Timestamp: 2026-11-25. Sources: `site/index.html`, `README.md`, `../COMMUNITY_CONTRIBUTION_PROGRAM.md`,
`../GITHUB_README_AUDIT.md`.

- GitHub repository used everywhere: `https://github.com/ganeshkrishnareddy/novara`.
- Site community links verified locally: Star, Fork, Watch releases, Explore source, Report a bug,
  Request a feature, Start a discussion, Read documentation — each opens the correct official destination
  with `target="_blank" rel="noopener noreferrer"`.
- Actions are voluntary and performed by the visitor on GitHub. Nothing automates starring, forking or
  following; no traffic is fabricated and no click is represented as a star or fork.
- Contribution program rewards substantive work under human review, never stars or follows.
- README audit confirms 8/8 banned-item rows pass: no incentivised engagement, no fake counts,
  no testimonials, no unverified badges.
- Privacy: optional OAuth needs explicit consent, minimum scopes, secure server-side session and
  account deletion controls; a manual verification path exists.

Limitations: link destinations were verified as text and local resolution, not by clicking on GitHub.
No live GitHub analytics were used or fabricated.
