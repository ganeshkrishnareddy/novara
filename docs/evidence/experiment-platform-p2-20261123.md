## Scope

Five named acceptance tests were added in
`apps/api/tests/test_experiment_platform_p2.py` and one static UI wiring guard
in `apps/api/tests/test_ui_wiring.py`. Every test drives the real FastAPI app
against the real generated OpenAPI document, real persisted credential rows and
real workspace-scoped role bindings. No app code is mocked.

The clean-room module `apps/api/novara_core/modules/experiment_platform.py`
owns one additive workspace-scoped table created by Alembic revision
`b1c2d3e4f5a7` (down revision `a8b1c2d3e4f5`). It reports the live OpenAPI
schema, counts real REST operations and stores default-role bindings. Personal
and server API credentials are the existing scoped `api_keys` layer; no new
secret store is introduced.

## Delivery boundary (important)

The OpenAPI status and REST inventory are computed from NOVARA's own live app,
not copied from GrowthBook. Credentials are NOVARA's existing one-time-secret,
hashed-at-rest API keys; no external identity provider is used. Default roles
are an experimentation overlay mapped to NOVARA's permission vocabulary. No
GrowthBook source, hosted platform, external webhook, provider or SDK is
contacted.
