## Defects and fixes

1. Bare company domains rendered as a dash — fixed before this QA log; recorded
   in `docs/CHECKPOINT_2026-11-22.md`.
2. Raw validation JSON (including the rejected input) was shown in the form
   error and toast when the API returned a 422 — observed independently in
   rounds 1, 2 and 3. Fixed in `apps/web/app.js` `errMessage()`: FastAPI detail
   arrays are now reduced to their readable `msg` values, so the UI shows only
   "Value error, secret field is not accepted: config.api_key". Re-verified
   live after the fix: `node --check` clean, full suite `99 passed, 2 warnings
   in 77.78s`, and the reproduced 422 showed the clean message with the dialog
   left open and no secret persisted. No blocking defect remains in the new
   screens.

All three rounds are now complete. The remaining release gates are outside this
UI scope: PostgreSQL/containers, installers and owner decisions.
